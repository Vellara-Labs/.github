# Vellara Labs

**Building blocks for asset eligibility, transfer policy, and lifecycle rules on Stellar.**

Tokenizing an asset is only part of the work. Applications also need holder eligibility, transfer policies, and rules tied to an asset's lifecycle — Vellara brings those examples together in one inspectable Soroban repository.

## What we build

- **Eligibility on-chain** — A trusted verifier records an approval decision on-chain; identity documents stay off-chain.
- **Transfer policy** — Rules that decide who may hold or move an asset, expressed as contract logic rather than process.
- **Built to adapt** — Each building block is meant to be explored, forked, and fitted to a project's own testnet prototype.
